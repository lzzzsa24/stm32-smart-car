# 模式 3 出弧成功：对应最外侧先灭后亮

按用户最新规则，模式 3 进入 `EXIT TURN` 或 `EXIT LINE` 后：

- 左转只看最左侧探头 X2，右转只看最右侧探头 X4。
- 该探头必须先不见黑线，再见黑线。进入出弧时已见黑且一直保持，不算成功。
  若进入出弧时已经不见黑线，则这就是首次“灭”。
- 对应探头重新见黑的同一控制周期立即完成出弧；不要求另外三个探头、
  中间见线、额外去抖、航向或行程满足条件。其余三个全黑也不阻止成功。
- 立即清除方向和弧段导航，撤销出弧电机命令，交给模式 2 共享正常循线。
  “忽略另外三个”仅用于成功判定；恢复普通循线后仍使用四路实际传感器。

出弧开始仍由现有 30°/40° 等导航条件决定。在普通路段、PROBE 或 ARC
期间，最外侧灭亮不会直接结束一轮弧段。`EXIT TURN` 到 `EXIT LINE` 的
交接保留本轮灭亮记录；新一轮出弧重新初始化，不沿用上一圈的记录。

原先“中间见线稳定即可完成”“自然直线验证即可完成”“需在 ±40° 内
才能完成”的自动成功路径已经取消。自然离弧证据只切到被动循线阶段，
仍等对应最外侧事件。未捕获时原有超时/里程撤销与手动 STOP 保留。

此规则替代 `MODE3_RING_RECONTACT_EXIT.md` 的角度确认方案。出弧开始前
的全白寻线（任意中间捕获）、两秒观察、22% 停车、模式 4 和速度保持。

测试覆盖左右各 16 种传感器组合，55° 大偏角下成功、刚进入时一直亮
不成功、先灭再全黑成功、其他三路变化不能提前成功、同周期交还普通
循线和后续丢线不复活旧转向。旧出弧流程测试补充了显式外探头事件，
不再用中间见线代替新的完成条件。完整回归、编译与交接见交接包。
无本次实车/串口/烧录操作。
