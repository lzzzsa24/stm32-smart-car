# 模式 3、4 持续使用模式 2 的慢速状态

用户反馈上一版过快，要求相同的行驶速度应取模式 2 的慢速状态。
以 `7b56dad` 为起点，保留回退分支 `rollback/sign-before-mode2-slow-7b56dad`。
主干状态核对到 `29d4956`，板上记录为综合版 `16b5092`，已包含上一版修改。

## 速度来源和行为

复用 `line_tracking.c` 中模式 2 重新接线后的 SETTLE 分支及原参数，
仅在模式 3、4 的调用中持续选用慢速档。每次调用携带选择，不写全局模式
开关；模式 1、2、5 的原接口仍使用原来的自动速度状态。

| 场景 | 左 / 右侧编码器目标，CPS |
|---|---|
| 直行、全黑、短缺口、出弧直行 | 1412 / 1412（原模式 2 的 2200 等效档） |
| 仅左内 / 右内修正 | 1412 / 2357，或镜像（原 2200 / 2400 等效档） |
| 相邻两个传感器见线 | 1412 / 2400，或镜像 |
| 最外侧纠偏、圆弧选支及出口对齐 | 0 / 2200，或镜像 |
| 丢线搜索 | 保留模式 2 的 2493 CPS 反向搜索及现有陀螺仪范围 |

“同一慢速档”指始终使用这组已有的直行与纠偏参数；转向时两侧仍有速度差。
取消此前强制 3815 CPS 的直行，也不再进入正常巡航的高速曲线分支。
模式 3、4 不因识别帧、全黑或圆弧另加 500/700/1200 CPS 的临时上限。
两秒识别停车、25% 触发门槛、未确认时 0.5 秒后重试、方向确认、鸣笛、
RGB 关闭和圆弧进出判断均保留。

DriveBase、编码器接口、PI、电压补偿和电机映射没有修改。
上述为闭环目标，不是已测得的轮速或赛道通过结果。
