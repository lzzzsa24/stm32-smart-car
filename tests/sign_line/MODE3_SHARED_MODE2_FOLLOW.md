# 模式 3 复用综合测试模式 2 寻线

基线：综合测试提交 `59407274e55efd292b187e393ddcf28d0dd40474`。
回退标签：`rollback/mode3-before-mode2-follow-5940727`。

## 行为范围

模式 3 在普通循线、已入弧的循线/丢线恢复、被动 EXIT LINE 阶段，
直接调用模式 2 的 `line_tracking_compute()`，启用同一 middle guard。
不再用另一套 ARC 白地角度搜线覆盖该计算结果，也不再把其直行目标
改写为 1412 CPS。电机仍通过原 `line_tracking_apply_command()` 和
DriveBase 编码器闭环执行。

| 传感器条件 | 复用的模式 2 行为 |
| --- | --- |
| 中间两路见黑 | 左右轮目标均为 1800 CPS |
| 仅一路中间探头见黑 | 内侧 1412、外侧 1800 CPS 修正 |
| 一路中间及同侧外探头见黑 | 内侧 0、外侧 1800 CPS 修正 |
| 两路中间均不见黑，包括只有最外侧见黑 | 立即进入模式 2 搜线，以正负 1800 CPS 差速旋转 |
| 全黑横线 | 使用模式 2 的 1800 CPS 横线处理 |

搜线方向和再次见线后的恢复，沿用模式 2 的传感器历史与编码器规则。
搜线过程中单独碰到外探头不会立即反转；其方向信息用于后续白地处理。
这套行为包含原地搜线，不能将软件一致性测试解释为已经消除了实车掉头。

## 保留的模式 3 导航行为

- 两秒停车观察保持不变。停车时全白的专用归中搜线仍要求中间两路
  见线后重新计满两秒；它不是普通寻线完成条件。
- PROBE/SELECTING 的标志方向约束与主动选支、主动出弧指令保持不变。
  此时由导航接管，速度不等同于普通模式 2 寻线目标。
- 停车航向优先的角度判定、再次见黑时退出主动出弧控制、旧方向清理
  保持不变；没有新增角度门限。
- 模式 4 保留自身 ARC 曲率恢复路径；模式 1/2/5 的入口没有修改。
- K210、识别阈值、鸣笛、RGB、硬件映射及手动 STOP 没有修改。

middle guard 设置函数只在配置实际变化时重置滤波，避免模式 3 每个
控制周期重新设置同一配置破坏正在进行的寻线。

## 验证边界

`test_mode2_follow.c` 使用真实跟线/恢复/DriveBase 代码，比较模式 2
与模式 3 普通、ARC、EXIT LINE 阶段各 2000 个样本的四轮目标、控制值、
PWM 及动作，包括时钟回绕、全白、边缘、全黑和恢复切换。
另覆盖真实导航链的停车、选支、出弧释放及手动 STOP。

执行标志导航完整主机测试、寻线完整主机测试与正式 ARM 构建。
主机传感器、编码器和航向输入为模拟数据；并未烧录、接串口或实车验证。
