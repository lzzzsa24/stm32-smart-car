# 降低寻线直线冲刺速度

起点：9a5d22da4f2fff8f70d1367bdfa7ccfc5e761dba。
用户要求减小直线冲刺速度；本次仅调整增强寻线的直线目标。

| 参数 | 原值 | 新值 |
|---|---:|---:|
| 平滑直线起点，等效 PWM 参数 | 2800 | 2600 |
| 平滑直线最高，等效 PWM 参数 | 3000 | 2700 |
| 非平滑居中直行上限，等效 PWM 参数 | 3000 | 2700 |
| 对应最高目标轮速 CPS | 5273 | 3815 |

等效 PWM 参数经既有 DriveBase 映射成闭环 CPS 目标，不是直接限死实际电机 PWM。
最高轮速目标下降约 27.6%，平滑直线起点由 4301 降至 3329 CPS。
保持居中 350 ms 后每 20 ms 增加 20 等效 PWM 的渐进加速规则。
实际底盘速度仍取决于轮胎、地面和滑移；没有实测速度结论。
