# 短暂外沿观测与丢线搜索方向

用户观察：直线冲出黑线前，最右侧传感器灯闪了一下，丢线后却向左搜索。
本次修改基于 worker `65acc30ae2849f95d22b08f97cfb3780633ad490`，保留横向短黑线过滤。

## 已复现的原因

实体旋钮决定模块的数字输出阈值；程序没有灰度幅值可供降低。此前方向记忆也需要
持续至少 4 ms，一次右外沿采样尚未确认就变成全白，会留下空方向，最终默认向左。
新增回归在旧代码上失败：右外沿单次采样后丢线，左右目标为 -2493/+2493。

## 修改后的行为

- 正常寻线和低速接线阶段，无歧义单侧外沿或同侧相邻两路只要采到一次，就记住该侧。
- 方向记忆与立即转弯分开：外沿仍需连续 12 ms 才直接进入持续转向；单帧先弱差速前行。
- 全白短缺口宽限结束后，用最近有效方向搜索。接线后新出现的另一侧外沿可覆盖上一轮方向。
- 三路/四路或不相邻多点黑优先判为歧义，清除方向；其后 100 ms 穿越窗口忽略尾沿。
- 原方向有效期 200 ms、稳定居中 80 ms 清除、模式重置清除保持不变。
- 未得到有效新方向时，正常态仍使用原默认左转；接线态仍可沿上一轮搜索方向恢复。

## 验证

`cmd /c tests\line_recovery\run.cmd` 包含：左右外沿各单次采样，在两种平滑设置和
两种全白设置下均朝最后外沿搜索；单帧不直接对转；接线阶段新反向外沿覆盖旧方向；
宽线及其尾沿、居中、过期和模式重置清除；系统计时回绕。原所有寻线、真实 DriveBase
联合模拟、轮速助力、故障处理和 RAM 日志回归继续运行。

## 边界与集成

灯闪不证明 MCU 采到了该脉冲。如果黑线窗口完全位于两次采样之间，此修改无法补回。
单独外沿噪声也会暂存方向；后续宽线会清除，但始终只有单侧的干扰仍可能影响搜索。
这是在窄窗口下保留最后出线方向的明确取舍，不意味着四个数字探头可以辨别所有图案。
