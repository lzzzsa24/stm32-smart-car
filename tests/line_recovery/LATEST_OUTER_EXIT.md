# 搜索过程中始终接收最新外侧出线方向

起点：c0192ff4f436b1467d50a837488e004fec341a24。
用户反复观察：锐角最后亮的是最右传感器，丢线后却继续左转。

## 已复现的漏分支

LineRecovery_ObserveDirection 原有一次性 exit_direction_armed 门控。
第一次外侧出线或 200 ms 窗口到期后，只有中间传感器再次出现才允许更新。
因此“旧左转 -> 白区 -> X4 右外侧短亮 -> 白区”即使已被软件采样，
仍可一直左转。此前测试甚至要求忽略窗口关闭后的新外侧边沿，这与用户当前
要求的“最后明确外侧信号优先”冲突；本次同步修改了该行为契约和测试。

最初新增回放的 48 项中旧版错误 24 项，包含左右镜像及 1 ms HAL tick/GPIO 队列输入。
输出保存在 before.log；这是合成输入回放，不能当作实车失败率。

## 当前规则

- 删除一次性开关。搜索多久、之前纠正过几次，都不妨碍接受新外侧边沿。
- X4 单独黑或 X3+X4 同侧黑记为右；X2 单独黑或 X2+X1 同侧黑记为左。
- 接触期间记录最新候选，不立即反转。后续全白且候选未超过 200 ms 时采用它。
- 新中间/模糊组合覆盖旧候选；多个外侧信号依时间顺序取最后一个。
- 横线仍由寻线主控制器优先处理；旧候选过期后不反转，等待新的有效边沿。
- 继续沿用轮速斜坡完成电机换向，不增加整车停顿；4 ms 捕获、鸣响与遥控停止保留。
- 代价：如果电气噪声刚好模拟“单外侧 -> 白”，也可能更新方向；四路数字输入
  无法仅从这一种图样证明实际道路身份。本次不再将所有后续外侧信号一律当作噪声忽略。
