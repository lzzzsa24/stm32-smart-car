## 控制变化

| 项目 | 原值 | 模式5新值 |
|---|---|---|
| 居中直行目标范围 | PWM等效2600～2850，约3329～4544 CPS | PWM等效2800～3050，约4301～5521 CPS |
| 居中加速确认 | 350ms | 120ms |
| 每20ms直行目标递增 | PWM等效20 | PWM等效40 |
| 普通中间传感器曲线中心值 | PWM等效2800 | PWM等效2900，转向修正增益乘1.25 |
| 单外侧初始修正 | 内侧0、外侧2200 CPS | 内侧0、外侧3200 CPS |
| 单外侧持续后反向差速 | 120ms后±2200 CPS | 60ms后±3200 CPS |
| 同侧相邻双传感器前进修正 | 内1412、外2400 CPS | 内1700、外3400 CPS |
| 回线低速阶段 | 500ms | 120ms，且仍要求近期中间传感器证据 |
| 回线阶段中间单侧修正 | PWM等效2200/2400 | PWM等效2400/2750 |
| 横线/短缺口前行 | PWM等效2200 | PWM等效2400 |
| 转向速度环目标斜坡 | 每20ms最多700 CPS | 快速转向授权有效时最多1100 CPS |
| 转向欠速补偿 | 40ms确认、上限600 PWM、每ms增加5 | 20ms确认、上限900 PWM、每ms增加20 |

PWM等效值只用于现有CPS换算，不直接写入电机引脚。启动脉冲原逻辑保留，本次没有加入
周期性大功率通断脉冲：连续速度PI叠加按轮欠速补偿，避免另一个等待/断电间隔。
补偿在反馈达到85%目标、反向反馈、失效/过期授权时清除，总输出仍不超过3599。
快速转向授权只接受20ms内下一条目标一致的命令，60ms不续期自动失效；直行、
固定绕障、普通模式、位置控制不继承。换向仍先经过零目标，保留必要的电机换向过程。

未改固定路线250/300mm、4000-CPS绕障行进、45度回线、超声16～22cm阈值、
红外关闭、遥控STOP、1ms传感器采样、横线100ms保护及60ms短缺口确认。
完全丢线的搜索目标和方向记忆算法不变。
