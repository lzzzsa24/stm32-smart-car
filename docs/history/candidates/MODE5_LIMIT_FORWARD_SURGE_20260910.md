# 模式5抑制前冲与误恢复候选

用户确认烧录4335b19脉冲方案后，模式5冲出赛道且原地搜索找不到线。
当前共享记录为综合4eda8fe，已包含该方案。实际冲出原因未经串口或运动测量；
源码中确认存在以下会放大风险的行为：前进修正使用固定高PWM脉冲、快速直行目标高、
单次中间接触立即结束搜索并恢复较快前进。本次针对这些行为调整，不宣称已确定全部物理原因。

## 调整

- 模式5正常修正只在左右目标反号时使用3300PWM脉冲。左右同向的弧线/前进修正
  恢复四轮连续速度PI和原有转向欠速补偿，避免一轮轮向前跳。
- 居中直行PWM等效目标2800～3050降为2550～2750，CPS约4301～5521降为3086～4058。
  中间传感器曲线中心PWM等效2900降为2700。外侧修正目标3200 CPS保持。
- 快速搜索捕获改为两次不同时间戳的有效中间命中，间隔不得超过30ms。
  同一时间戳重复计算不算新证据。第一下接触保持±1800 CPS的低速旋转，不向前冲；
  下一次独立命中即可进入回线，不新增固定毫秒等待或停车。
- 单中间捕获后，以1412/2200 CPS连续前进修正，保存实际找到线的方向。
  两个中间传感器同时在线后才退出该回线限制并按直线斜坡加速。
  若一直只能命中单中间，则继续低速修正，不因定时器到期自动加速。
- 普通模式的4ms捕获确认不变。全白仍立即原地搜索，没有增加后退动作或定时停车。
  固定绕障25/30cm、4000CPS、超声阈值和STOP优先级未改。
