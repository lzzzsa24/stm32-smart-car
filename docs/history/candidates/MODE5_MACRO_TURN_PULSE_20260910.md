# 模式5正常修正转向的宏观脉冲候选

起点768bc53c36eb0cfae28ef3dc1ee6936e9a100a27；独立分支test/mode5-fast-follow-20260909。
用户确认只作用于模式5正常寻线转向，直行、丢线搜索、固定绕障和普通模式不启用。

## 运动方式

- 驱动阶段逻辑PWM为3300/3599，沿用motorPWM的四轮功率/极性映射。
- 每40ms一轮，最多驱动24ms，其后停驱16ms，立即进入下一轮；没有额外等待阶段。
- 停驱是输出零，不调用整车DriveBase_Stop，不清除寻线/运动所有权，不主动反向制动。
  车身会不会真正静止取决于惯性与赛道摩擦，此处不能保证。
- 同侧双传感器前进修正按左右CPS比例分配本轮驱动宽度。例如1700/3400为12/24ms。
- 每轮按目标CPS乘40ms形成各轮的编码器微动量上限；达到上限就提前停驱。
  已结束的脉冲不会因回弹或同轮目标增大而再次通电。可疑编码器轮使用时间上限。
- 转向重复命令不重置相位；方向变化先停驱16ms，再沿新方向驱动。
  停驱中再变方向只更新下一次方向，不延后原到期时间，避免抖动导致永远不动。
- 脉冲期间不积分普通速度PI，也不累计启动补偿；目标CPS用于方向、比例和微动量，
  不是承诺脉冲期间的连续实际轮速。PWM高幅值保持固定，没有额外提高硬件上限。

## 所有权与计时

新命令需在准备后20ms内按完全匹配的左右目标接受，60ms不续期取消脉冲授权并回到
普通速度控制。直行/普通转向/搜索/位置/STOP/制动与故障不能继承脉冲。
取消脉冲时先清零输出，避免清除截止计时器后仍留下高PWM。

主循环计算相位、编码器截断和下一次驱动。1ms HAL时钟只关闭到期输出，不启动运动，
也不做编码器采集、PI计算或阻塞操作。主循环批量安装截止时间与四轮输出时使用短
临界区，防止中断刚停驱后主循环又写回剩余车轮。主循环卡顿时不会由中断补发脉冲。
截止精度仍受1ms中断及中断屏蔽延迟影响。
