基线主干36f4aed；综合测试来源a217df8。回退标签：
`rollback/2026-09-10-before-main-four-mode`。旧综合测试分支保留作来源，
后续开发请从新main建立分支；不要继续把旧五模式编号当成当前接口。

## 模式映射

| 新模式 | 来源 |
|---|---|
| 1 | 原主干模式1，循迹＋自适应绕障 |
| 2 | 原主干模式2，纯四线循迹 |
| 3 | 综合a217df8模式3，四线循迹＋标志导航 |

没有模式5。遥控/串口5不改变当前模式，0停车。上电保持STOP。

## 行为

模式3保留全部来源更新：观察阈值20%；全白时1800-CPS闭环搜索任一中间探头，
之后观察2秒；相对停车参考航向达到设定有符号角度启动出弧，完成只看对应
最外侧先灭后亮。默认40°，遥控独立+/-每次5°、范围30°～90°，
模式切换保留RAM设置，重启恢复默认。方向键仍控制音频，不与+/-混用。
鸣笛标志播放一遍；OLED显示设定角、IMU标定状态和相对航向。

模式4使用综合快速循迹3600-CPS普通直行上限和宽线目标；固定绕障
250/300mm、45°回线、4000-CPS直行与回线，保留连续衔接、急刹与回线捕获。
超声基础16cm、动态上限22cm、清空28cm；侧红外关闭，不能保证侧面无碰撞。
模式1/2的控制器、DriveBase、电机方向、编码器和原避障关键路径不变。

## 验证与限制

主机回归覆盖旧循迹、隔离新循迹/真实DriveBase、标志状态机、固定绕障、
模式切换、5无入口、0最高优先级、音频、遥控调角和K210运行逻辑。
源码等价检查验证模式1/2保留及模式3/4来源。STM32正式编译和链接通过。
测试目录中mode5是历史名字，现由新模式4调用；未删除旧实验和测试源码。
新组合未烧录、未悬空、未地面测试；之前综合版的烧录证据不可替代本版验证。
因此作为预发布候选版，实际转角/防撞/识别效果须在实车确认。
