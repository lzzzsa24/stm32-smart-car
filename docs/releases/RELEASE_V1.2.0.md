## 模式3最终增量

保留20%观察阈值、全白1800-CPS搜索任一中间探头后观察2秒、单次鸣笛。
达到有符号设定角后直接沿当时航向直行，不再先对准停车航向。
编码器闭环前进，陀螺仪提供小幅航向修正；对应外侧探头在出弧开始后的
新采样中先灭再亮，才恢复普通循迹。默认40°，独立+/-键每次5°，
范围30°～90°；模式切换保留，重启恢复40°。方向键音频功能不变。

重要限制：出弧直行无原时间/距离上限；陀螺仪失效只取消修正，仍前进。
探头未再次捕获时可能持续驶离赛道，模式3不靠避障传感器停车，请保持
遥控0可用，并留出安全空间。目标轮速与轮子里程不保证实际车体轨迹。
