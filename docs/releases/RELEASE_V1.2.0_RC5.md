# v1.2.0-rc.5：模式5固定路线黑线绕障

将综合测试版 `58c3744` 的模式1移植为主干模式5，替换原K210视觉寻线。
其他主干模式1～4不升级为综合测试版的控制器。

## 使用

- 遥控/串口数字5：四线循迹＋固定路线绕障，OLED `M5 BYPASS`。
- 数字0：停车。上电仍默认STOP，未自动运行。
- 模式1：保留原主干红外、自适应绕障、10～16 cm超声触发。
- 模式2：保留原纯四线循迹。
- 模式3/4：保留主干原有SL2＋路标逻辑和K210程序，不是综合版的新模式3/4。

## 新模式5参数

- 向右偏移250 mm、平行前进300 mm、45°斜向回线；实时黑线捕获接管。
- 固定两段直行和斜回线目标4000 CPS；自适应短探测仍限1800 CPS，
  退回自适应后的连续回线限2100 CPS。转向2500 CPS，后退1900 CPS。
- 超声基础触发16 cm，动态上限22 cm，清空28 cm，前瞻100 ms。
- 原始10 cm近回波立即制动；绕障前进段15 cm保护，丢弃旧朝向回波。
- 直线居中保持后允许2850等效PWM上限；其他模式不启用这一加速。
- 侧向红外发射和触发禁用；切回其他模式恢复原使能状态，不把标定失败改为成功。
- 不需要K210。旧视觉解析/控制源码仍保留为历史参考，但不再控制模式5电机。

## 兼容与证据边界

四个编码器AB接口、电机方向、DriveBase PI、电池补偿和音频遥控不变。
主干模式1的自适应回线1800 CPS与原超声临界5 cm通过独立配置保留，
不被新模式5的较快参数污染。主机测试覆盖实际模式选择、反复5/1切换、
标定失败恢复、旧视觉路径移除，以及新旧绕障/循迹/标志/音频回归。

本发布未烧录、未做悬空或地面测试。4000 CPS是目标，不是实测速度；
侧红外关闭、较近触发和轮胎滑移均可能造成碰撞，需在留有空间的赛道测试。
构建/主机模拟通过不能证明实际绕行距离、刹车余量和通过率。

## 固件与K210

使用本发布的STM32 BIN/HEX，不要误用工作树中的旧综合固件。
常规烧录应只擦应用页，保留音频记忆 `0x0807F000` 和标定 `0x0807F800`；
整片擦除会清空两页。SHA256SUMS.txt记录各资产哈希。

模式5无需K210程序。本发布仅附主干模式3/4对应的路标脚本、模型、清单，
不再附旧模式5视觉寻线脚本作为活动功能。文件名 `sign_mode34.py` 对应
板端 `/sd/main.py`；模型路径 `/sd/KPU/road_sign_det/road_sign_det.kmodel`。

回退标签：`rollback/2026-09-09-before-mode5-fixed-bypass`。
