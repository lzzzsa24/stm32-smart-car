# 全模式整合候选版 v1.2.0-rc.2

本预发行版在 `v1.2.0-rc.1` 的全模式整合基础上，将模式 1 的超声波与
黑线绕障动力参数正式纳入主干。功能源码提交为
`317022123395016354249c3c7bc9e9b26c02ff7e`。

## 本次变化

- 模式 1 超声波低速前进和倒退命令由 2200 提高到 2600。
- 模式 1 旧超声波转向内外侧命令由 2300/2800 提高到 2800/3300。
- 主动黑线绕障参数明确设为：倒退 1900 CPS、前进 2600 CPS、越过障碍
  探测 2200 CPS、回线 2300 CPS、转向 2500 CPS。
- 模式 2--5、电机方向映射、四轮 AB 编码器映射、上电默认 STOP 和
  Flash 最后一页保留策略不变。

此前临时测试提交 `074ef682` 的寻线强边缘修复没有合入本版本；不要把
本 Release 描述为同时包含该独立提交。

## STM32 产物与验证

- ARM 编译和链接通过：text/data/bss 为 `84384/64/11536`。
- BIN 大小：84452 字节。
- BIN SHA-256：
  `14B484C5091A3549B24360236F941A61CC12688D34900427D73EFAC2D181E9C0`
- HEX SHA-256：
  `D30049A841C4F9C43F2925C118CDA70C675E45D0B2774D87C94D734549BF7AA8`
- 完整 line-recovery/bypass 主机回归通过，包括两档搜索速度、四轮
  DriveBase、模式 1 绕障和 STOP 所有权。
- 该 BIN 已通过 STM32 ROM Bootloader 写入 84452 字节并完整读回校验，
  随后 `GO OK`。烧录前后均确认模式 0 和四轮零输出。
- 尚未进行本版本的悬空或落地避障测试。

## K210 资产

本次 K210 程序没有变化，仍提供两套互斥的 `/sd/main.py` 选择：

- 模式 3/4：`k210-mode34-sign-main.py`，配合
  `k210-mode34-road-sign.kmodel`。
- 模式 5：`k210-mode5-visual-line-main.py`，不使用标志模型。

同一时刻只有一个脚本能够作为 K210 的 `/sd/main.py`。切换模式组时需
手动替换脚本并复位 K210。

## 证据边界

电脑端构建、主机回归、STM32 写入/读回和 GO 已完成；这些结果不等于
悬空测试或地面避障测试成功。实车测试时应保持遥控 STOP 随时可用。
